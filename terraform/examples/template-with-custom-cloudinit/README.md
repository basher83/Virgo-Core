# Template with Custom Cloud-Init Example

This example demonstrates creating a Proxmox VM template with custom cloud-init user-data configuration.

## Overview

The example:

1. Uploads custom user-data.yaml to Proxmox snippets storage
2. Downloads a cloud image from URL
3. Creates a template with custom cloud-init configuration

## Prerequisites

- Proxmox VE with API access
- SSH access to Proxmox host (required for template creation)
- Cloud image URL (default: Ubuntu 24.04 LTS)

## Usage

1. Copy and configure variables:

   ```bash
   cp terraform.tfvars.example terraform.tfvars
   cp user-data.yaml.example user-data.yaml
   ```

2. Customize `user-data.yaml` with your cloud-init configuration

3. Deploy:

   ```bash
   tofu init
   tofu plan
   tofu apply
   ```
